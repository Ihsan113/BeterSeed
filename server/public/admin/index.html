Pulihkan atau migrasikan

Periksa isi backup sebelum mengganti data. Seluruh sesi akan berakhir setelah pemulihan.

Panduan migrasi & cakupan backup
  1. Buat backup dan simpan frasa sandinya secara terpisah.
  2. Di VPS tujuan, pasang versi backend dan skema yang sama. Gunakan TOKEN_PEPPER dan DATA_ENCRYPTION_KEY dari server asal agar login, autentikator, dan validasi pembelian tetap bekerja.
  3. Masuk ke admin tujuan, pilih backup, periksa ringkasan, lalu konfirmasi pemulihan.
  4. Masuk kembali dengan akun admin yang ada dalam backup. Arahkan aplikasi ke server baru setelah pemeriksaan selesai.

Backup mencakup data aplikasi, bukan konfigurasi VPS, file .env, kredensial Google, atau aset CDN. Sesi, OTP, email antrean, dan batas percobaan tidak dipindahkan. Cadangan browser dibatasi 32 MB data sebelum enkripsi; database yang lebih besar memerlukan backup terkelola.

Pemulihan mengganti seluruh data ke waktu backup, termasuk saldo dan riwayat pembelian. Gunakan cadangan terbaru dan hentikan aktivitas pengguna selama migrasi. Perubahan oleh alat SQL di luar BetterSeed harus dihentikan secara terpisah.
