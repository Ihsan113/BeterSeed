# Batch 10: Fantasy Shop Preview

## Functionality
- Responsive browse page with four categories
- Featured Premium Garden Pass preview modal
- Preview-only item detail sheets
- Soundscapes category reserved for properly licensed sound packs
- No payments, no actual item ownership or cosmetics activation

## QA priorities
- 360x640 screen has no RenderFlex overflow
- Large device text fits all cards and preview sheet
- Each category can be selected and cleared
- See all / Popular toggle is functional
- Shop and back to Garden do not interrupt ambient audio
- Previews never claim a real payment was made
